# i-have-adhd

An ADHD-friendly output skill for AI agents.

It makes responses action-first, numbers multi-step work, keeps state visible across turns, suppresses tangents, gives concrete time estimates, and preserves depth when an explanation needs it.

## Included files

- `i-have-adhd/SKILL.md` — skill instructions
- `i-have-adhd/agents/openai.yaml` — OpenAI/Codex metadata
- `i-have-adhd/agents/gemini.toml` — Gemini metadata
